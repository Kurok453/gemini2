# Вебхук для навыка Яндекс Алисы (Gemini + Serper)

Готовый шаблон вебхука для навыка Алисы. Код редактировать не нужно: разместите репозиторий в Vercel, добавьте два API-ключа и укажите адрес вебхука в Яндекс Диалогах.

Как это работает: Алиса передаёт реплику на ваш адрес `/api`, Gemini формулирует ответ, а если нужны свежие данные (новости, погода, курсы), вызывает поиск через Serper. Контекст диалога хранится в состоянии сессии Алисы.

## Развёртывание

1. Создайте на GitHub новый репозиторий и загрузите в него все файлы из этой папки. Если это шаблон, который вы получили из чужого репозитория, нажмите Fork.
2. Откройте https://vercel.com/dashboard и нажмите Add New… → Project.
3. В списке Import Git Repository выберите свой репозиторий и нажмите Import.
4. Нажмите Deploy и дождитесь завершения первого развёртывания.
5. В проекте Vercel откройте Settings → Environment Variables.
6. Создайте переменные окружения, выбрав Production для каждой:
   - `GEMINI_API_KEY` — ключ из Google AI Studio: https://aistudio.google.com/app/apikey
   - `SERPER_API_KEY` — ключ из Serper: https://serper.dev
7. После сохранения ключей откройте Deployments и выберите Redeploy для последнего Production-развёртывания. Дождитесь статуса Ready.
8. В Vercel откройте Settings → Domains, скопируйте свой домен и добавьте в конец `/api`. Например: `https://YOUR-PROJECT.vercel.app/api`.
9. Откройте свой навык в Яндекс Диалогах (https://dialogs.yandex.ru/developer). В настройках Backend вставьте этот полный адрес в Webhook URL и сохраните изменения.
10. Включите опцию «Использовать хранилище данных в навыке», чтобы сохранять контекст между репликами.

## Проверка

Откройте адрес `https://YOUR-PROJECT.vercel.app/api` в браузере. Должно появиться сообщение `Alice webhook is running`. Затем в консоли разработчика Диалогов, на вкладке «Тестирование», напишите навыку любой вопрос.

## Необязательные настройки

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `GEMINI_MODEL` | Модель Gemini | `gemini-2.5-flash` |

## Важно знать

- Алиса ждёт ответ не больше 3 секунд. Если Gemini или поиск не успели, пользователь услышит просьбу повторить вопрос. Поэтому используется быстрая модель, а ответы просят делать короткими.
- Ответ Алисы ограничен 1024 символами, состояние сессии — примерно 1 КБ. Код сам обрезает историю диалога, оставляя последние реплики.
- Слова «хватит», «выход», «стоп», «пока» завершают навык.
- Ключи хранятся только в переменных окружения Vercel. Не добавляйте их в код и не публикуйте.
- Бесплатные тарифы Gemini и Serper имеют лимиты на число запросов.

## Структура

```
api/index.js   — вебхук (обработка запроса Алисы, Gemini, Serper)
package.json   — описание проекта

```
